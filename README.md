# Кам’янець — туристична мапа

Адаптивний навчальний прототип туристичного вебзастосунку. Готова статична версія розташована в `dist/`.

## Можливості

- 18 туристичних об’єктів у п’яти категоріях;
- пошук, фільтри та синхронізовані список і позначки;
- адаптивний режим карти/списку;
- картки з умовами відвідування, доступністю та джерелом;
- посилання на кожен об’єкт у Google Maps.

Для повноцінного підключення Google Maps JavaScript API потрібен окремий браузерний API-ключ із дозволеним доменом.
